# 🛒 Mes Prochaines Courses

Application web progressive (PWA) de gestion intelligente de listes de courses.

## ✨ Fonctionnalités

- 📝 **Multi-listes** avec filtres (Toutes / En cours / Terminées)
- 🛍️ **Articles détaillés** : quantité, unité, catégorie, prix unitaire
- 💰 **Calcul automatique** du budget total et reste à acheter
- 🎤 **Ajout par saisie vocale** (Web Speech API)
- 📤 **Partage de liste** par texte copiable
- ☁️ **Synchronisation cloud** via code de sync
- 📊 **Statistiques avancées** avec graphiques (top catégories, budget par magasin)
- 📋 **Modèles de listes pré-remplies** (5 templates : semaine, petit-déj, fête, ménage, équilibré)
- ⏰ **Rappels** programmés avec notifications navigateur
- 🎯 **Mode courses** : vue condensée pour faciliter les courses en magasin
- 📤 **Export PDF** de la liste (jsPDF)
- 🔍 **Détection des doublons** lors de l'ajout d'articles
- 🔄 **Duplication** de listes en un clic
- 🏷️ **Tri** (nom, catégorie, date, statut) et **regroupement** par catégorie
- ♿ **Accessibilité** : aria-labels, focus visible, aria-live
- 📱 **PWA installable** comme application native
- 100% **gratuit, sans pub, sans achats intégrés**

## 🚀 Déploiement

L'application est déployée sur Vercel : https://mes-prochaines-courses.vercel.app

## 🛠️ Stack technique

- HTML5, CSS3, JavaScript vanilla (aucune dépendance runtime)
- Service Worker pour le mode hors-ligne (PWA)
- Web Speech API pour la saisie vocale
- Notifications API pour les rappels
- jsPDF (CDN) pour l'export PDF
- localStorage pour la persistance des données
